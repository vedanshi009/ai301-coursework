# Procedure: how this skill grades a plan package

## Read order
1. Issue summary — context only.
2. Repro evidence, in full — every step and number. Note each distinct result before reading anything else's opinion about it.
3. Candidate plan: diagnosis, scope, changes, test plan — note each claim separately.
4. Candidate plan comment — note anything not already in the plan sections.
5. Thread highlights — note competing theories or conventions.

## Evidence gathering
For each check, pull the specific fact from its named Evidence source (per rubric.md) and record it as a short note: the claim, and the repro result(s) it's checked against. No check is graded from memory of the whole package — only from these recorded notes.

## Check execution
1. Grade diagnosis first; use its verified result (not the plan's raw claim) when grading scope and fix-targets-cause.
2. Grade each remaining check strictly from its recorded note.
3. Evidence absent or too thin → `unclear`. Never grade `pass` on confident wording alone.

## Verdict assembly
Apply rubric.md's verdict rule to the per-check grades. Quote the recorded note for whichever required check is the first fail or unclear, as the output's deciding evidence.
